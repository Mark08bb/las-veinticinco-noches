LAS VEINTICINCO NOCHES — EDICIÓN VISUAL INSPIRADA EN LOVABLE

Esta edición traslada el lenguaje visual del proyecto original de Lovable a la web estática de GitHub Pages: azul noche y lapislázuli, oro envejecido, acentos turquesa, tipografías editoriales, patrón geométrico girih, arcos y paneles de pergamino.

Se conserva la aplicación JavaScript que usa el proyecto de GitHub y su conexión existente con Supabase y la función edge editor-desk. No importa el backend, las tablas, el inicio de sesión ni el almacenamiento del proyecto de Lovable.

INSTALACIÓN
1. Descomprime el ZIP.
2. En el repositorio Mark08bb/las-veinticinco-noches, reemplaza index.html, styles.css y app.js por estos archivos.
3. Sube también bosforo-invierno-hero.jpg a la raíz del repositorio, junto a index.html.
4. No modifiques Supabase ni sus secrets.
5. GitHub Pages publicará la nueva apariencia desde main / (root).

La imagen del Bósforo se mantiene de forma discreta en la cabecera. Las puertas se dibujan con CSS, no dependen de la ilustración fotorrealista anterior.
