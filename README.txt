Para actualizar GitHub Pages, sustituye los archivos anteriores por TODOS los archivos de esta carpeta:
- index.html
- styles.css
- app.js
- bosforo-invierno-hero.jpg
- puerta-otomana.webp

La ilustración de la puerta se reutiliza en las 25 posiciones del calendario. El número se superpone en el medallón central vacío. Las puertas siguen siendo botones reales: las publicadas y abiertas se pueden pulsar; las demás permanecen selladas. El escritorio de Mehmed y la conexión con Supabase se mantienen.

No hay que modificar Supabase ni sus tablas o políticas.
