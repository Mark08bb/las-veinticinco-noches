LAS VEINTICINCO NOCHES — ACTUALIZACIÓN DE LA WEB

Contenido:
- index.html
- styles.css
- app.js

Instrucciones:
1. Abre el repositorio GitHub Mark08bb/las-veinticinco-noches.
2. Entra en cada uno de estos tres archivos.
3. Usa el icono del lápiz (Edit this file) o Add file > Upload files.
4. Sustituye los archivos existentes por los de esta carpeta (o sube los tres juntos desde el ZIP y confirma la sustitución).
5. Confirma los cambios en la rama main.

No borres ni cambies la configuración de Supabase. La actualización conserva:
- La tabla stories y sus 25 registros.
- La función editor-desk y sus secretos.
- El registro mínimo de aperturas.
- La clave pública de conexión ya configurada.

El acceso al editor aparece como un botón visible “Escritorio de Mehmed”.
Tras introducir la clave, el panel muestra las 25 puertas en una lista. Puedes seleccionar cualquiera y editar título, acto, sinopsis, relato, URL de imagen, fecha y estado de publicación.
